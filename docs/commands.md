# Commands

Anyone can use these. They do not need operator permissions.

| Command | Shows |
| --- | --- |
| `/skippingstone records` | Your own best skips and distance |
| `/skippingstone records <player>` | Another player's records. Works for players who are offline. |
| `/skippingstone records top` | The top 10 players by skips |
| `/skippingstone records top skips` | Same as above |
| `/skippingstone records top distance` | The top 10 players by distance |

Ties on skips are broken by distance, and ties on distance by skips.

To show records on screen permanently, use the [scoreboard objectives](./guide/records#scoreboard).
